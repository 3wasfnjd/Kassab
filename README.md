# كسّاب · Kassab

لعبة هجولة في الطعوس للجوال، عالم مفتوح فيه حي نجدي وواحة ومزرعة وبيت شعر ومخيم بدو، بأصول عبودين قيمز.
**عبودين قيمز · ABODEN GAMES**

كل محتوى اللعبة داخل هذا المستودع، بدون أي روابط خارجية.

## التشغيل
افتح `index.html` من سيرفر (مثلاً GitHub Pages من إعدادات المستودع: Settings ← Pages ← Branch: main).
الأفضل الجوال بالعرض.

## التحكم
- اسحب يسار الشاشة يمين/يسار: الدركسون
- بنزين / فرامل / هاند
- ↺ يرجّع السيارة، «راديو» يغيّر الأغنية، الخريطة الصغيرة تكبر باللمس

## ما في اللعبة
- طعوس طبيعية، غبار وآثار كفرات (للسيارة وللمركبات الثانية)
- يوم كامل كل ١٠ دقائق، أنوار السيارة والفوانيس والخيام في الليل
- طقس تلقائي: صحو، غبار، غائم، عاصفة رملية، مطر
- وادي يسيل مع المطر ويتجمع ماؤه عند المزرعة
- وايت مغرّز تفزع له وتسحبه بالحبل، ووانيت يروح ويرجع على الطريق
- ناس وإبل وغنم يتحركون ويبعدون عن السيارة

## الملفات
| المسار | المحتوى |
|---|---|
| `index.html` | اللعبة |
| `lib/three.min.js` | محرك Three.js r149 (رخصة MIT في `lib/three-LICENSE.txt`) |
| `aa/` | مولّدات الأصول من مستودع Aboden-Assets (نخيل، عمارة نجدية، بيت شعر، إبل، ناس، مركبات) |
| `fonts/` | خط Baloo Bhaijaan 2 (رخصة OFL في `fonts/OFL.txt`) |
| `models/car.glb` | موديل الوانيت للعب (مخفّف: ٢٥ ألف مثلث، خامة ١٠٢٤، أقل من ١ ميقا) |
| `models/car_orig.glb` | الموديل الأصلي كما هو، لشاشة البداية فقط (٥١١ ألف مثلث، خامة ٢٠٤٨، ١٧ ميقا) |
| `radio/` | أغاني الراديو: أربع مقاطع (الأول والثاني ٣٠ ثانية، الثالث ١٩ والرابع ٢٠) (`1.mp3` … `4.mp3`) |
